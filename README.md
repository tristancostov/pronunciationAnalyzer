## Используемые технологии
| Назначение | Инструмент |
|---|---|
| Язык реализации | Python 3.9 |
| Распознавание речи (offline) | VOSK, модель `vosk-model-ru-0.42` — слова и их временны́е метки |
| Морфологический анализ | pymorphy2 — лемма, часть речи |
| Определение ударения | ruaccent — словарь ударений |
| Акустические признаки | librosa — MFCC, RMS-энергия, ZCR, форманты (F1/F2) через LPC |
| Сигнальная обработка | scipy.signal — поиск пиков (`find_peaks`), фильтр Баттерворта |
| Численные операции | numpy |
| Сравнение текста и слогов | difflib (`SequenceMatcher`) |
| Конвертация аудио | ffmpeg — приведение к 16 кГц / моно / 16-бит PCM |

**Ключевые алгоритмы:**

- **Слогоделение** — по принципу восходящей звучности (адаптация
  алгоритма с Хабра), применяется к произнесённой форме слова.
- **Поиск ядер слогов в аудио** — метод de Jong & Wempe: энергия в
  низкочастотной полосе гласных (≤ 1000 Гц), голосовой фильтр (исключение
  глухих согласных), пики с порогом энергетического провала; число ядер
  согласуется с известным из текста числом слогов.
- **Анализ редукции** — внутреннее сопоставление слогов: безударные слоги
  сравниваются с ударным по длительности, энергии и формантной
  централизации (смещение F1/F2 к центру гласного пространства).

### Папки

- **`audio/`** — все входные записи в правильном для VOSK формате
  (16 кГц, моно, 16-бит PCM). Имя файла соответствует имени текста в
  `text/` (например, `audio/1fori.wav` ↔ `text/1fori.txt`).
- **`text/`** — эталонные тексты: то, что говорящий должен был
  произнести. Используются для сравнения с распознанным и для
  слогоделения.
- **`vosk-model-ru-0.42/`** — распакованная модель распознавания
  (содержит `am/`, `conf/`, `graph/`, `ivector/`, `rescore/`, `rnnlm/`).
- **`syllables_export*/`** — результат работы `extraSegAudio.py`: каждый
  файл внутри — это один вырезанный слог в формате WAV; имя вида
  `NN_слово_слог.wav`. Используются для проверки на слух точности
  слоговых границ. Разные папки соответствуют разным записям.

### Скрипты

- **`pronunciationAnalyzer.py`** — основной скрипт. На вход принимает
  один аудиофайл и его текст (пути заданы в начале файла), на выход даёт
  консольный отчёт и JSON-файл с полным разбором.
- **`extraSegAudio.py`** — берёт готовый `<имя>_syllable_analysis.json`,
  по сохранённым временны́м меткам слогов вырезает соответствующие
  фрагменты из исходного WAV и сохраняет их в папку `syllables_export*/`.
- **`test*.py`** — вспомогательные скрипты для отдельных проверок.

### Файлы результатов

- **`<имя>_syllable_analysis.json`** — основной результат анализа одной
  записи. Содержит: распознанный и эталонный текст; пословный разбор
  (`wordAnalysis`) с временны́ми метками, слогами, их границами в аудио,
  акустическими признаками (энергия, форманты), ударным слогом и
  анализом редукции; таблицу контраста слогов ударный/безударный
  (`syllableContrast`); ошибки на уровне слов и слогов
  (`wordComparison`, `syllableErrors`); паузы.
- **`syllable_frequency.json`** — сводный частотный словарь слогов по
  всем обработанным текстам (какой слог сколько раз встретился).
- **`pipeline_result.json`** — сводный результат прогона.

## Данные и источники

Записи разделены на две категории (отражено в именах файлов):

- **`*fori*` — речь неносителей (иностранцев).** Сюда входят, в
  частности, собственные записи чтения заданного текста.
- **`*local*` — речь носителей.** Фрагменты вырезаны из видеоблогов
  (vlog) русскоязычных носителей. Источник обширный и удобный для
  дальнейшего пополнения базы записей.


## Подготовка аудио (обязательно)

VOSK корректно работает только на формате **16 кГц, моно, 16-бит PCM**.
Приведение из любого формата одной командой:

```
ffmpeg -i входной_файл -ar 16000 -ac 1 -c:a pcm_s16le audio/имя.wav
```

## Запуск

1. Положить запись в `audio/`, её текст — в `text/` (с одинаковым именем).
2. В начале `pronunciation_analyzer.py` указать имена файлов:
   ```python
   audioFile = os.path.join(SCRIPT_DIR, "audio", "имя.wav")
   textFile  = os.path.join(SCRIPT_DIR, "text",  "имя.txt")
   ```
3. Запустить анализ:
   ```
   python pronunciation_analyzer.py
   ```
   На выходе — консольный отчёт и `имя_syllable_analysis.json`.
4. (Опционально) вырезать слоги для проверки на слух:
   ```
   python extraSegAudio.py
   ```

## Обозначения в отчёте

- `´` после слога — **ударный слог**.
- `[ядер:N≠слогов:M]` после слова — **сниженное доверие к границам**:
  акустически найдено N ядер при M слогах в тексте. Сегментов в выводе
  всегда столько, сколько слогов; пометка указывает, что часть границ в
  этом слове поставлена приближённо.
- `↻` — замечание по редукции (безударный слог недостаточно отличается
  от ударного).
