# V3 音节核校正说明（研发阶段一次性工作）

这些 `*_v2_to_review.TextGrid` 已由声学算法自动预标注。人工校正只用于
建立训练集、开发集和最终测试集，不是应用以后要求用户完成的步骤。

## 本轮建议顺序

先做最短且母语/非母语平衡的四份；每完成一份就另存，不必一次做完：

1. `5fori_v2_to_review.TextGrid`（约 56.7 秒）
2. `1local_v2_to_review.TextGrid`（约 64.2 秒）
3. `4local_v2_to_review.TextGrid`（约 69.1 秒）
4. `1fori_v2_to_review.TextGrid`（约 81.2 秒）

第二批再做 `6local`、`2local`、`4fori`、`5local`、`2fori`。
`8fori` 是封存的最终盲测文件，不加入训练；V3 参数冻结后只评估一次。

## Praat 操作

1. 同时打开同名 WAV 和 `*_v2_to_review.TextGrid`。
2. 同时选中 Sound 与 TextGrid，点击 `View & Edit`。
3. 新文件只有 `nucleus` 点层，没有 `syllable` 层，这是正常的。
4. 从录音开头检查到结尾：正确的 `N` 保留；位置明显偏离元音稳定主体时拖动。
5. 辅音噪声或鼻音/流音造成的错误峰删除；漏掉的实际元音核补一个 `N`。
6. 弱读元音只要实际可听见就保留；完全省略则不标。无法确定时标为 `?`。
7. 另存为同目录下的 `*_v2_reviewed.TextGrid`，不要改变 `nucleus` 层名称。

例如第一份保存为：

`D:\Mycode\analysis\v2_annotations\5fori_v2_reviewed.TextGrid`

## 统一判据

- 一个实际发出的元音核对应一个点，不按拼写中的元音字母机械计数。
- 点放在元音周期纹理和 F1/F2 最稳定的主体中部，不放在辅音—元音过渡处。
- `/м н л р й в с/` 等辅音本身不产生元音核；单辅音介词 `в/с` 也没有核。
- 相邻两个实际元音若分别形成两个可听核，就标两个点；合流或省略则按声音标。

当前九份新预标注共约 12.2 分钟、2486 个候选点。通常只需改少数点，
不需要从零创建标注。
